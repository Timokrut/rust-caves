RUST CAVE FINDER — программа для Windows 10/11 x64

ЗАПУСК
1. Запусти RustCaveFinder.exe двойным щелчком. Установка не нужна.
2. Программа найдёт папки Steam и откроет самый свежий скачанный файл .map.
3. Если выбран другой сервер, выбери нужный файл в выпадающем списке.
   Или нажми «Открыть .map» и укажи карту вручную.

Твоя проверенная карта Rustburg #1:
A:\SteamLibrary\steamapps\common\Rust\maps\proceduralmap.4250.6112026.290_3517362123.map
Размер 4250, сид 6112026; найдены 5 стандартных пещер.
После вайпа нужен новый файл карты. Зайди на сервер, чтобы Rust скачал его,
затем нажми «Обновить» и выбери новый файл.

УПРАВЛЕНИЕ
Колесо мыши — масштаб относительно курсора.
Левая кнопка + перетаскивание — перемещение карты.
Щелчок по пещере в списке — подсветка и точные координаты X/Y/Z.
Двойной щелчок по записи — приближение к пещере.
Двойной щелчок по кругу — выбор пещеры.
Двойной щелчок по пустому месту / «Вся карта» — сброс масштаба.
«Копировать координаты» — координаты выбранной пещеры в буфер обмена.
«Карта PNG» — сохранить всю карту с кругами и номерами.
«Координаты CSV» — сохранить список для Excel и других программ.
Файл .map можно перетащить из Проводника на окно программы.

О КАРТЕ
Изображение строится из рельефа, биомов, водоёмов и дорог самого .map.
Это упрощённая отрисовка: здания РТ и игровые текстуры не показаны.
Круг обозначает позицию объекта пещеры, а не точку входа.
Вход может находиться рядом, в том числе в соседней клетке.
Распознаются 9 стандартных типов пещер Rust. Авторские пещеры, собранные
из отдельных деталей, автоматически не распознаются.

Программа работает офлайн и только читает выбранные файлы карт.
Поддерживается формат World Serialization 10, LZ4 Legacy.
Предел файла: 256 МБ, распакованных данных: 512 МБ.
Нужен встроенный в современные Windows .NET Framework 4.5 или новее.

ИСХОДНЫЙ КОД
RustCaveFinder.cs — полный исходный код без сторонних библиотек.
build.ps1 — сборка встроенным компилятором Windows, без установки SDK.
Проверено на реальном файле Rustburg: декодирование, все 5 позиций пещер,
сетка, рельеф суши/воды, CSV и отрисовка окна. Проверена обработка
повреждённых блоков LZ4 и обрезанного protobuf.

Описание формата карты: https://wiki.facepunch.com/rust/Map_Data
Формула сетки: https://commits.facepunch.com/504506
